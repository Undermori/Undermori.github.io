M²Shelf——一个适合赛博仓鼠的本地媒体库

发表于2026-08-26|更新于2026-09-01|资源分享
|字数总计:921|阅读时长:2分钟|阅读量:

M²Shelf （“MORI MEDIA SHELF”）

是一个完全由Codex完成，面向 Windows 本地媒体收藏的资源浏览器。

一时兴起，方便自己看库存动画随手搓的小工具，目前只适用于整理番剧、电影本地收藏，非自动化追番媒体库。很难想象，这么一个小东西居然花光了两个gptpro5x的额度。

M²Shelf 把本地硬盘、移动硬盘或 NAS 映射目录中的动画、电影及相关资源建立为独立索引，提供海报墙浏览、Bangumi 元数据、标签、收藏夹、观看记录和外部播放器入口。

定位

  • 本地媒体索引工具，不是播放器，也不是媒体服务器
  • 读取本地硬盘、移动硬盘或 NAS 映射目录
  • 用海报墙、列表、目录层级重新组织资源
  • 索引信息保存在应用自己的 SQLite 数据库里

功能

  • 支持多个资源库，递归扫描任意深度目录
  • 资源库可选择按文件夹识别或按视频文件识别
  • 支持海报墙、紧凑列表并提供真实目录层级浏览
  • 支持本地显示名、真实文件名、Bangumi 多语言标题和用户标签搜索
  • 支持 Bangumi 自动匹配、手动搜索、重新绑定和清除绑定
  • 支持视频、字幕、图片、音频、文档、压缩包、字体、播放列表等附属资源索引
  • 支持用户标签、一层命名收藏夹、批量编辑和最近观看
  • 支持外部播放器启动和 Windows 资源管理器定位
  • 支持简体中文、English、日本語、한국어
  • 支持跟随系统、亮色和暗色主题

设计边界

  • 媒体源始终只读
  • 不移动、不删除、不重命名真实文件
  • 不向媒体目录写入 NFO、海报、数据库或临时文件
  • 扫描、标签、收藏夹、绑定和观看记录只保存在应用数据库或缓存中
  • 删除资源库只删除索引，不删除磁盘内容

Bangumi

  • 主要元数据来源
  • 自动匹配会提取目录名、文件名和父目录信息
  • 会过滤字幕组、编码、分辨率、校验码和集数等噪声
  • 只接受动画 type 2 和真人影视 type 6
  • 封面可自动下载，也可手动选择
  • Bangumi 可以在设置中关闭

播放与定位

  • 不内置播放器
  • 通过用户配置的外部播放器打开视频
  • 播放器路径作为独立参数传递
  • 成功启动播放器后记录最近观看
  • 支持在资源管理器中精确定位文件
  • 非视频附件按系统默认程序打开

更新

  • 使用固定的 GitHub Release latest.json
  • 只接受规范的 major.minor.patch 版本
  • 检查、下载、安装互相独立
  • 下载后会校验文件大小、SHA-256 和 Ed25519 签名
  • Portable 和 NSIS 都是稳定通道

使用方式

  1. 完整解压 Portable ZIP
  2. 双击 M2Shelf.exe
  3. 添加媒体目录
  4. 选择识别方式
  5. 扫描资源库
  6. 配置播放器和 Bangumi

Portable 只是指应用本体无需安装，但数据库、设置和缓存仍会写入 Windows 应用数据目录。

当前构建未做 Authenticode 签名，Windows SmartScreen 可能提示“未知发布者”；界面依赖 Microsoft Edge WebView2 Runtime。
