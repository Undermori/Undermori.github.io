通过GitHub Pages上线网站相关配置

GitHub Pages 是一项静态网站托管服务，它直接从 GitHub 上的存储库获取 HTML、CSS 和 JavaScript 文件，可选择通过构建流程运行这些文件，然后发布网站。

和上一篇的图床一样，GitHub优点是免费、简单、快速，缺点是国内IP访问偶尔会抽风，再就是域名相对于有自己服务器的情况来说不够那么个性化（用户名+github.io），根据自己的情况与需求选择就好。

  1. 浏览器登陆自己的GitHub账户，点击页面顶部右上角的“+”，然后选择“New repository”。

  2. 在新页面为仓库命名为”你的用户名.github.io“并勾选“Public”，点击“Create repository”创建仓库。

  3. 仓库设置中找到Pages，记住仓库地址和分支
